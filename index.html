Catatan pengujian

Website ini menggunakan bobot dari CNN_reg_final.keras, tanpa pelatihan ulang. Preprocessing gambar mengikuti input RGB 64 × 64 dan normalisasi nilai piksel / 255. Angka akurasi 92,55% berasal dari data uji penelitian, bukan hasil pengujian webcam atau gambar baru. Penggunaan kamera bertujuan mendemonstrasikan inferensi model.

Informasi kesesuaian dengan penelitian

Model terdiri dari empat blok Conv–BN–ReLU dengan tiga tahap pooling, Global Average Pooling, dan Dense Softmax. Bobot CNN asli diekspor ke tensor Float32 untuk diproses di TensorFlow.js. Proses resize pada browser menggunakan Canvas; hasil dapat berbeda kecil dari PIL pada Python.
